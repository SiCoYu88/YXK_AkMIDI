# Repository working instructions

Before analyzing or modifying an AkAudioSampler/Wwise-driven Niagara system,
search `AkPlugins/AkAudioSampler/Docs/AkWwiseNiagara粒子改造方案库.md` by asset
name, Niagara module, Data Interface type, and visible symptom.

Reuse a documented solution only after confirming that the emitter count,
Particle Update data flow, Simulation Target, renderer bindings, and
cross-emitter dependencies match. If no documented solution applies, inspect
the asset first and append the new verified solution to the same document.
